# IUsage Windows 测试版

支持范围：Windows 11 x64。非官方工具，使用的接口可能变化。目前未签名，Windows 可能出现安全提示；请核对下载来源与 SHA-256，不要关闭安全防护。

1. 解压发布 ZIP 到只有自己能写入的本地目录。无需管理员权限；不要在共享目录运行。
2. 运行 `IUsage.exe`。点击 C/X 切换服务，点击进度条打开详情，右键打开菜单。
3. Claude：右键 → **Claude 登录设置…**。未安装 Claude Code 时，可使用网页登录；点击“如何获取？”了解 sessionKey 的本机获取方式。组织 ID 通常留空，多个组织时指定。已有 Claude Code 登录则点“改用本机 Claude Code 登录”。单独登录 Claude 桌面客户端不适用。
4. Codex：先在 Codex 客户端或 CLI 登录；程序使用本机 `~/.codex/auth.json`。
5. 等待正常刷新。已有缓存、限流等待会被保留，保存登录信息不会额外发送验证请求。

sessionKey 是敏感登录凭据，不是只读用量 key。仅粘贴到本机应用，不要分享给任何人。详细数据流向见随包 `PRIVACY.md`。

更新：退出旧版，覆盖 exe 后重新运行；设置和缓存保留。0.1.15 起新安装默认 55 秒刷新；已有配置保留原值，如需提速，退出程序后将 `%APPDATA%\IUsage\settings.json` 中 `poll_secs` 改为 `55` 再启动。限流等待不会提前结束。卸载：取消开机自启，退出后删除 exe；如需清除个人配置，再删除 `%APPDATA%\IUsage\`。

反馈前请阅读 `SECURITY.md`，不要上传凭据或整个配置目录。多显示器、睡眠唤醒、长时间驻留等兼容性仍需更多用户验证。
